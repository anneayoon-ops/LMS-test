    Task 7: Content Optimizations — 3 Pages¶

    Output file: content/content-optimization-brief.md

    This brief drives content updates to the 3 in-scope pages. It is shared with the SEO team for review before being handed to the copywriting/authoring team.

    Step 1: Audit Existing Content¶

    • For each of the 3 in-scope pages, fill in this audit table
    Element Current Gap / Issue
    H1
    Meta title
    Meta description
    Intro paragraph
    Internal links present
    Missing links (per Task 5 interlinking rules)
    Content gaps vs. competitors
    Redundant content shared with sibling pages

    Run this table for each page:

    • [Ad Type] Product page
    • [Ad Type] Tips & Best Practices page
    • [Ad Type] Specs page

    Step 2: Write Optimization Recommendations¶

    • For each page, write a recommendations section

    Cover these 5 areas per page:

    1. H1 update (if needed)

    Format: Current: [text] → Recommended: [text] → Rationale: [1 sentence]

    2. New inline links to add

    Use rules from Task 5 Step 3. For each link:

    • Exact placement in body copy
    • Link text
    • Destination URL

    3. Related content card copy

    Card Title Description (1 line)
    Card 1
    Card 2

    4. Breadcrumb label check

    Confirm the page's current title matches the proposed breadcrumb text. Flag any mismatch — breadcrumb text and page title must align.

    5. Content gap fills

    Describe any content that needs to be added. Example: "Add 1–2 sentence intro to Specs page describing what [Ad Type] is and linking to the Product overview page."

    Step 3: SEO Review¶

    • Share content/content-optimization-brief.md with SEO team

    Request review on:

    • Keyword alignment for recommended H1s and section headings
    • Meta title and meta description updates
    • Internal linking equity — do the proposed links distribute PageRank appropriately?

    Tracking SEO changes

    Track all changes resulting from SEO feedback with inline comments in the doc: "SEO feedback: [describe what was changed and why]"
