    Milestone Checklist¶

    Phase 1 — Research¶

    • Current-state dead-end audit complete
    • Competitive audit (Facebook, Amazon) documented
    • Stakeholder alignment session held

    Phase 2 — Architecture¶

    • FigJam ecosystem map created (current + proposed + delta)
    • 3 in-scope pages selected with rationale documented
    • IA review checkpoint approved — stakeholders + AEM team

    Phase 3 — Design¶

    • 4 interlinking concepts created and annotated
    • Pattern direction decided and captured in FigJam
    • Wireframes for 3 pages complete (desktop + mobile)
    • Wireframe review + AEM validation done

    Phase 4 — Specs¶

    • Breadcrumb hierarchy spec complete (all page types)
    • Card interlinking rules defined
    • Inline link placement guidelines written
    • Hi-fi designs complete for 3 pages (desktop + mobile)
    • Custom components documented on Component Proposals page
    • Hi-fi design review resolved

    Phase 5 — Production¶

    • Content optimization brief written and SEO-reviewed
    • Figma designs annotated for production
    • LEM handoff notes doc complete
    • Production kickoff meeting held
    • Localization brief + string CSV sent to loc team
