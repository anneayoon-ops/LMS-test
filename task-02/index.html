    Task 2 · Ecosystem IA Map¶

    Phase 2 — Architecture
    Deliverable ia/lms-ads-ecosystem-ia-map.fig
    Owner UX Lead
    Done when Full stakeholder group approves proposed IA and 3 in-scope pages are confirmed

    Steps¶

    • Create FigJam with 3 sections

      Section Purpose
      Current State Existing page structure, as-is
      Proposed State Redesigned ecosystem architecture
      Delta / Changes What's new, what changes, what stays

    • Map the current state — color-code every page as a node; add pain-point sticky to each dead end

      Color Page type
      🔵 Blue Hub pages
      🟢 Green Product pages
      🟠 Orange Tips pages
      🟣 Purple Specs pages
      🔴 Red Dead ends — add sticky: "Pain point: [what the user can't find here]"

      Label each node: page name · abbreviated URL · breadcrumbs Y/N · primary CTA.

    • Design the proposed state — apply all 6 interlinking patterns

      # Pattern Show in FigJam as
      1 Triad linking (must-have) Thick bidirectional arrows between product ↔ tips ↔ specs
      2 Hub links Thin arrows from every leaf page → hub page
      3 Persistent nav module Box labeled "Ad Type Nav Module" on each node
      4 Breadcrumbs Annotate each node: e.g. Advertise > Ads > Video Ads > Specs
      5 Related content cards "Related" module box at the bottom of each node
      6 Inline contextual links Sticky on product nodes: "Body copy links to Specs + Tips inline"

    • Select 3 in-scope pages — one complete ad-type triad (Product + Tips + Specs)

      Decision criteria: - Highest organic search traffic — confirm with SEO team - All 3 pages exist with substantial content - Document rationale on FigJam node: "In scope because: [reason]"

      Page selection is deferred intentionally

      The IA work surfaces which ad-type triad has the most fragmented ecosystem and highest SEO opportunity — that becomes the design target.

    • IA review checkpoint — stakeholders approve; AEM team flags unbuildable components as red stickies → these become design constraints for Task 4
