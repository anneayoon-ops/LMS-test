    Task 4 · Wireframes — 3 In-Scope Pages¶

    Phase 3 — Design
    Deliverable wireframes/lms-ads-ecosystem-wireframes.fig
    Owner UX Lead
    Done when AEM validation complete; all constraints captured as red Figma annotations

    3 pages × desktop (1440px) + mobile (375px) = 6 frames minimum. Grayscale, placeholder content throughout.

    Steps¶

    • Build reusable template

      Zone Content
      Site shell LMS global header, footer, primary nav (placeholder)
      Breadcrumb row [L1] > [L2] > [L3] — linked text nodes
      Hero H1 + subtitle + primary CTA placeholders
      Body Text block placeholders, 2/3-width column
      Related module "You might also need" — 2-card layout
      Mobile Single-column stack; breadcrumb shows last 2 nodes

    • Product page — desktop + mobile

      Breadcrumb: Advertise > Ads > [Ad Type]

      [Hero: Ad Type name · subtitle · "Start advertising" CTA]
────────────────────────────────────────────────
What is [Ad Type]?    [Body copy]
                      [→ Inline link: Tips page]
                      [→ Inline link: Specs page]
────────────────────────────────────────────────
Why use [Ad Type]?    [Body copy]
────────────────────────────────────────────────
Example placements    [Image × 3]
────────────────────────────────────────────────
You might also need
[Tips card]           [Specs card]

      Annotations required:

      Element Annotation
      Breadcrumb 'Ads' → /advertise/ads · '[Ad Type]' = current page, no link
      Inline link 1 End of creative specs section → Specs page
      Inline link 2 After product description → Tips page
      Cards Always show the other 2 pages; never repeat current page

    • Tips & Best Practices page — desktop + mobile

      Breadcrumb: Advertise > Ads > [Ad Type] > Tips & Best Practices

      [Intro paragraph]
────────────────────────────────────────────────
Tip 1: [Title]        [Body copy]
                      [→ Inline link: Specs — character limits]
Tip 2–N: [Title]      [Body copy]
────────────────────────────────────────────────
You might also need
[Product card]        [Specs card]

      Key annotation: '[Ad Type]' breadcrumb node links to the Product page — how users navigate back.

    • Specs page — desktop + mobile

      Breadcrumb: Advertise > Ads > [Ad Type] > Specs

      [Intro: 1–2 sentences + inline link → Product]
────────────────────────────────────────────────
Image Specs     [Table: Spec | Value | Notes]
Copy Specs      [Table: Spec | Value | Notes]
Technical Specs [Table: Spec | Value | Notes]
────────────────────────────────────────────────
You might also need
[Product card]        [Tips card]
      Element Annotation
      Intro inline link → Product overview page — context for search-entry users
      Specs table Each row self-contained (spec + value + notes) — LLM readability
      Section headers Anchor links on desktop; accordion on mobile
      Mobile tables Horizontal scroll
    • Wireframe review — stakeholders (UX alignment) + AEM engineering (component feasibility); all AEM constraints → red annotations in Figma
