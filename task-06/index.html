    Task 6 · Hi-Fi Designs — 3 In-Scope Pages¶

    Phase 4 — Specs
    Deliverable designs/lms-ads-ecosystem-hifi.fig
    Owner UX Lead
    Done when Design review resolved; version tagged v2 — post-review [date] in Figma history

    Design system: Our Community Design System — enable via Figma Assets → Team Libraries.

    Steps¶

    • Set up file

      Figma page Contents
      Page 1 — [Ad Type] Product Desktop + mobile frames
      Page 2 — [Ad Type] Tips Desktop + mobile frames
      Page 3 — [Ad Type] Specs Desktop + mobile frames
      Component Proposals Ecosystem Card + Specs Table specs

      Import existing LMS site shell (header, footer, global nav) — do not recreate from scratch.

    • Product page — desktop 1440px + mobile 375px

      Apply real content from the in-scope ad type. Token map:

      Element Token
      Page background color/surface/default
      H1 text/heading-xl
      Subtitle text/body-lg
      Primary CTA component/button/primary
      Breadcrumb — linked color/text/link + text/body-sm
      Breadcrumb — current color/text/secondary + text/body-sm
      Body copy text/body-md
      Inline links color/text/link (underlined on hover)
      Section dividers color/border/subtle
      Related card hover shadow/md

      Place inline links per Task 5 placement rules. Use Ecosystem Card for related content module.

    • Tips & Best Practices page — desktop + mobile

      Condition Decision
      ≤ 5 tips Numbered list — text/heading-sm per title, text/body-md per body
      6+ tips System accordion component — reduces scroll length
      Inline Specs link Style as color/text/link inline in body copy — not a CTA button

    • Specs page — desktop + mobile

      Use Specs Table component. Section structure: Image Specs → Copy Specs → Technical Specs.

      • Desktop: anchor links above table jump to each section
      • Mobile: horizontal table scroll + section headers collapse to accordion
      • Each row must be self-contained (spec + value + notes in one row — no sub-rows)

      LLM readability

      Add Figma annotation: "Each row is self-contained — spec name + full value in one row — for both human scanners and AI systems parsing the page."

    • Document custom components on the Component Proposals page — see Custom Components for specs

    • Design review

      Reviewer Focus
      Stakeholders Visual design alignment
      AEM / LEM eng Custom component feasibility
      SEO team H1s and section headings keyword-aligned

      Resolve every Figma comment. Log changes in version history as v2 — post-review [date].
